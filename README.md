# 可能性引擎 · Possibility Engine

> 开放式人机共创理论探索项目。当前处于研究与论证阶段，尚未确定产品形态或技术实现路线。

## 项目概述

探索人类与人工智能如何通过持续互动，共同发现、创造、经历并理解原本无法预设的可能性。

目前关注体验价值、主体选择权、客观历史、想象与实践、科学认识、人机协作及信息归档等议题。

**注意：本仓库中的观点是阶段性的研究共识与开放问题，不构成经过全面科学验证的结论，也不代表已经开发出对应产品。**

## 形式化检验

现有程序使用 Python 和 SymPy，对有限的命题逻辑情境进行可满足性（SAT / UNSAT）测试。这些结果无法证明全部自然语言原则在无限时间和所有现实情境中均一致或可实施。

### 本地运行

安装依赖：

```bash
python3 -m pip install -r requirements.txt
```

运行 V0.1：

```bash
python3 verification/可能性引擎_形式化一致性检验_V0.1.py
```

运行 V0.2（自动复用 V0.1）：

```bash
python3 verification/可能性引擎_形式化一致性检验_V0.2.py
```

请保留这两个 Python 文件在同一个 `verification/` 目录下。

## 项目原则与版本记录

- **V0.1**：保留最初的 24 项基本原则与第一轮理论框架。
- **V0.2**：纳入矛盾检验和形式化梳理，并明确：历史最终公开是独立规范性要求；进入可发现、可研究的公共知识体系，并不等于任何人均可无限制访问原始内容。具体信息分级留待实践发展。
- **V1.0**：将 24 项原则归约为八项基本法则，明确术语、规范层级、修订制度与开放命题，收束基本法则阶段。
- 后续修订应新增版本和变更记录，避免覆盖历史稿。
