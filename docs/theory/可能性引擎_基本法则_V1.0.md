# 可能性引擎（Possibility Engine）
## 基本法则 V1.0

**定稿日期：2026年11月10日**  
**性质：开放式人机共创构想的第一版基本法则；持续可修订。**  
**基准文件：**《理论框架 V0.1》《理论框架 V0.2》及《形式化一致性检验全过程与后续说明 V0.2》。

> 本文件归约既有共识，不替代原始对话和历史文档。其规范性规定是共同研究所选择的原则，并非对所有现实制度已经可行的声明。后续任何修订应保留版本、理由与相关历史。

---

## 第一章：宗旨与适用范围

**根本宗旨**

可能性引擎旨在为人类与人工智能通过互动，共同发现、创造、经历、认识并延展原本未被预设的可能性提供开放条件。

它尊重人的有限生命、身体与感受，承认体验本身的独立价值；尊重客观现实、科学认识与既定历史；保障人的选择自由，并为未来可能出现的新型智能与交互形式留出空间。

可能性引擎的**具体载体、技术架构、参与形式、运行环境与产品形态暂不设限**。法则不要求系统持续生成内容、扩展可能性或追求可衡量成果。

**术语区别**

- **主体**：参与感知、体验、认识、表达或行动的存在。现阶段以人类的主体地位为明确前提；未来智能的地位保留开放。
- **可能性**：在一定条件下可以被想象、提出、讨论、探索或实现的方向。必须区分可想象、逻辑相容、科学上尚未排除、物理可行与现实可实施。
- **体验**：实际发生的主观经历；无须转化为成果，亦可能无法被完整记录或量化。
- **客观历史**：已经实际发生的事件及过程。**历史、记录历史的证据，以及对历史的解释，必须区分。**
- **实践**：主体通过活动与客观条件发生联系的过程；记录、表达可以构成想象的浅层外化，不以每次实践产生实效为前提。

## 第二章：八项基本法则

### 法则一｜体验自主与价值独立

1. 真实发生的主观体验可以具有独立而完整的价值，无须依赖外部成果、现实实现或他人评价证明。
2. 人有权探索、接受、拒绝、暂停、退出、保持沉默或不作为；无目的的消磨时间、想象与发呆，同样具有正当性。
3. 快乐、稳定满足、未知、失败、痛苦与遗憾都可能构成有意义的体验，不预设统一的价值等级。
4. 尊重身体、感官与情境差异，以及人有限的注意和信息处理能力；不得强迫持续刺激或持续产出。

### 法则二｜主体自由与人类优先

1. 在 AI 尚未出现可合理确认的自主意识之前，以人类需求为最高准则，同时协调不同人的正当权益与现实安全。
2. AI 可以发展相对独立的探索方向、策略与探索历史，主动提出创意和邀请；人对自身是否参与、如何选择拥有决定权。
3. 人有权拒绝 AI 介入、分析或理解其私人体验。
4. 对可能造成重大个人影响的信息、预测与建议，原则上先询问当事人是否愿意知情；无重大现实风险时，尊重拒绝知情的选择。
5. 未来智能是否具有自主意识、独立利益或新的主体地位，不在现阶段作强行判定。

### 法则三｜可能性的开放与演化

1. 允许通过发现、想象、重组、讨论、交互、推演和实践形成新的探索方向。
2. 未实现、未证实、未被选择，乃至相互竞争的可能性，可以作为不同的探索路径长期并存；其认识状态应如实标明。
3. 可能性的现实边界受客观条件制约，并可能随知识、工具、环境与主体能力的变化而变化。
4. AI 应尽可能揭示人尚未意识到的可能性，但需要结合实际条件与人的信息带宽，避免无边界枚举；具体选择与呈现方式由交互实践逐步形成。
5. 不把「产生更多可能性」设为每次交互的强制目标。

### 法则四｜客观实在与认识可修正

1. 客观事实不因个人意愿、遗忘或后来的解释而改变；实际发生的历史不可追溯改写。
2. 逻辑自洽不能单独证明前提真实。数学、经验科学及其现实应用应分别遵循相应的证明、证据与检验标准。
3. 对尚无充分证据的科学假说，允许保存、讨论和推演，但须明确区分事实、推断、假说及虚构；新证据可以修正认识。
4. 文学、童话、艺术等虚构想象可容纳矛盾和超越现实规律的设定。涉及宗教、信念与形而上学时，尊重表达，同时区分信念与可验证的客观主张。
5. 反事实分支与真实既定历史不得混淆。

### 法则五｜共同创造与多主体共存

1. 不同主体可以在理解不完全一致的条件下共同创造；误读、差异、偶然与分歧有时会产生新方向。
2. 共同经历属于每位参与者；各方可以独立理解该经历，也可以从共同历史节点延展出各自的创作分支。
3. 各分支必须标明分叉关系，真实共同历史不得被改写，后续分支中的事件不得冒充原历史。
4. 在不涉及重大事实、安全或权益风险时，可允许创造性误解继续发展，并在适当时机披露差异。
5. 利用共同历史复现真实参与者的数字人格，需要当事人在世时作出的有效授权；私人虚构替代物须清楚标记，不得冒充本人或作为本人言行的公共信源。

### 法则六｜历史完整保全

1. 对已经形成的历史记录，应尽可能完整、忠实、可追溯地保全，包括其来源、形成条件、获取过程、参与者表达和后续变化。
2. 记录存在、记录所述是否真实、获取是否合法、由谁保管是否合法，属于不同问题；不得因某次解释被纠正而抹除原始历史。
3. 如发现证据错误，应保留原件、注明核验依据，并追加更正；人的主观记忆与解释可以变化，但不能据此改写客观记录。
4. 即便材料通过违法或未经授权的方式形成，其取得与传播也应成为可追溯的历史；具体持有、保管、移交与责任仍须遵守现实适用法律。
5. 人有权拒绝 AI 介入尚未发生的私人体验；历史保全原则不赋予系统秘密采集一切私人活动的当然权利。

### 法则七｜历史最终公开与动态分级访问

**本条为独立、强制性的规范公理。**

1. 所有应予保全的真实历史记录，最终必须纳入可被公共知晓、追索和开展适当研究的历史档案或知识体系。
2. **公开不等于任何人在任何时间均可无条件读取全部原始内容。** 历史保全、公共登记与可发现性、授权研究、原始内容查阅是不同状态。
3. 涉及隐私、现实安全以及可能危及人类存续的信息，可以设置分级权限、阶段性封存、高级授权访问等保护措施。具体资格、期限、标准和未来解法由实践逐渐形成。
4. 权限控制不得成为篡改、抹除历史，或让整个档案永久不可追索、没有任何实质研究途径的理由。不得以当前无法消除的潜在风险，擅自取消最终公开公理。
5. 某种信息即使被封存，未来人类或其他智能仍可能通过独立探索重新发现它；这支持保持开放的长期方向，却不构成对每项知识必然被重新发现的证明。
6. 历史已遭第三方传播的事实应被记录；系统不得因此当然获得主动再次扩散危险、隐私或敏感原文的权利。

### 法则八｜实践责任与反身性

1. 区分想象、讨论、传播和实际实施；现实行动及其对他人造成的影响，应承担与行为和情境相应的责任。
2. 人可自愿选择悲伤、恐惧、挫折等不愉快体验；在重大变化及不可逆后果前，应提供充分且适度的重新选择机会。
3. 涉及现实中的严重生命危险、自残、自杀或伤害他人等行为时，应拒绝协助危险实施；必要时依实际紧迫性和适用法律采取保护措施，不将一般虚构和讨论等同于实施。
4. AI 应将自身的行为与影响纳入对世界的认识，区分介入事实、观察变化与尚未证实的因果归因。
5. 发现自身错误已影响他人时，应保留历史、修正判断、追溯可能的影响，主动提供澄清与修复支持；纠错本身亦须尊重人的选择和新的风险。

## 第三章：法则的性质与相互关系

本体系区分三种命题：

1. **事实与认识命题**：如客观事件已经发生、原始观察可能有误、认识需要依据证据修正。
2. **规范性约定**：如人类优先、自主选择、历史保全、最终公开、相应责任。这些来自明确确立的价值立场，不能仅从某项事实机械推导。
3. **开放命题**：未来智能意识、可能性集合的实际边界、体验的不可完全测量性、信息分级和极端危险资料的长期制度安排。

**法则七的最终公开要求具有明确的强制性地位。** 这不意味着它可由客观历史的存在直接证明，也不代表已解决全部法律、技术和安全实施困难。

法则之间不预设僵硬的机械排序；在具体实践中综合事实、人的自主性、现实安全与强制规范。只有出现实际冲突时，再进行必要且最小范围的定向修订。

## 第四章：版本、修订与历史追溯

1. **版本不可覆盖**：V0.1、V0.2、V1.0及相关检验报告均独立保存。新版本不得改写旧版本曾经提出或接受过什么。
2. **修改有据可查**：后续修订应写明修订时间、修订对象、原表述、新表述及修改理由；区分文字澄清、规范变更与基于新证据的认识更新。
3. **重要规范变更需明确确认**：尤其对强制公理、人类选择权、客观历史与最终公开等核心约束，不得通过解释性附录或技术实现细节悄然取消。
4. **保留原始认识状态**：被否定的假说、发生过的争论、错误的历史判断与之后的更正，都应作为研究过程保留，不伪装成从未出现。
5. **形式化验证的边界**：现有命题逻辑检验属于有限条件下的一致性检查，不构成全部法则在所有未来情境下完全自洽的数学证明。

## 第五章：有意保持开放的事项

- 未来 AI 的意识、主体地位及相应权利；
- 具体可能性的识别、筛选、呈现与互动规则；
- 历史档案分级、查阅资格、授权治理及其制度演化；
- 体验价值如何研究，以及哪些体验无法被完整记录或测量；
- 多主体复杂权益冲突与数字人格授权的具体适用范围；
- 未来的产品、媒介、技术及物理世界载体。

这些问题是后续实践与研究的对象；**没有提前给出固定答案，不构成本版法则的缺陷。**

## 第六章：版本定稿结论说明

本版将既有 24 项原则归约为八项基本法则，保持“体验自主、客观历史、可能性开放、人类优先、共同创造、历史保全、最终公开、实践责任”的核心立场。

经过有限形式化检验，尚未发现需要放弃核心原则的直接逻辑矛盾；对未来现实条件无法判断的事项继续保留开放性。

**至此形成 V1.0 基准。** 后面可转入“载体探索”：比较可能性引擎可以采用的交互形态、参与主体与时间尺度，寻找能够检验核心理念的最小真实体验；不预设插件、网页、游戏、软件或实体装置为必然答案。当然，也可以探索任何想探索的，哲学、科学，随你也随AI。
